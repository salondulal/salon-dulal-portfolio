Environmental Scene Classification

Deep learning image classification across six environmental scene categories, comparing a baseline CNN with an improved MobileNetV2 transfer-learning model and evaluating robustness on noisy images.

What was implemented

  • Baseline CNN and improved MobileNetV2 pipeline with data augmentation and fine-tuning
  • Evaluation on clean and noisy test sets with confusion matrix and misclassification analysis
  • Six-class classification: Buildings, Forest, Glacier, Mountain, Sea, Street
Baseline (clean)67.38%
Improved (clean)90.71%
Baseline (noisy)51.90%
Improved (noisy)63.81%

What was learned

  • How transfer learning and fine-tuning can substantially improve performance over a baseline CNN
  • The impact of image corruption on model reliability and the need for robustness-aware evaluation
